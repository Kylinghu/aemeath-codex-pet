# Aemeath Codex Pet

A custom Codex pet package for **Aemeath**.

## Contents

- `aemeath/pet.json`
- `aemeath/spritesheet.webp`
- `qa/contact-sheet.png`

## Install

1. Create target folder:
   - `~/.codex/pets/aemeath/`
2. Copy:
   - `aemeath/pet.json` -> `~/.codex/pets/aemeath/pet.json`
   - `aemeath/spritesheet.webp` -> `~/.codex/pets/aemeath/spritesheet.webp`
3. Restart Codex app if it is already running.

## Notes

- `qa/contact-sheet.png` is included for quick visual QA preview.
- Generated from the validated hatch run at `D:/aimis/hatch-runs/aemeath`.
